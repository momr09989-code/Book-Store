# 📚 Book Fair & Literature 

A responsive, interactive e-commerce frontend web application built to simulate a seamless book-buying experience. This project highlights modern UI/UX principles and robust DOM manipulation using Vanilla JavaScript.

> 🔗 **[Live Demo: Experience the App Here!](https://momr09989-code.github.io/Book-Store/)**

---

## ✨ Key Features

- **Dynamic User Interface:** Clean, modern, and fully responsive design that adapts to all screen sizes (Mobile, Tablet, Desktop).
- **Interactive Book Catalog:** Users can browse through a curated list of books and view detailed information for each item.
- **Functional Shopping Cart:** 
  - Add items to the cart.
  - Update quantities dynamically.
  - Remove items seamlessly.
  - Real-time order total calculations.
- **Checkout Simulation:** A fast-paced, intuitive checkout form simulation that validates user input and handles state successfully.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic and accessible page structure.
- **CSS3:** Custom styling, Flexbox/Grid layouts, and smooth animations.
- **Vanilla JavaScript (ES6+):** Logic for state management, DOM manipulation, and handling user events without relying on external libraries.
